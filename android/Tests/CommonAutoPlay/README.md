# 共同线自动播放门控回归

运行：

```powershell
& '<AndroidRoot>/runtime/dotnet/dotnet.exe' run --project android/Tests/CommonAutoPlay/CommonAutoPlayRegression.csproj -- reports/android-common-autoplay-gate.json
```

第二个参数可指定真实章节目录，默认 `<数据目录>/主线第03-42章`。报告记录所读取的第 03、29 章 `pack.json` 校验值。

测试工程直接编译共享核心源码，在自己的输出目录构建，不编译安卓工程或写入共享核心的构建缓存。

`PlaybackEngine.EvaluateCommonAutoPlayNext()` 只读评估自动点击资格：

- `CurrentIsCommon`：当前位置已经确认、整句播放状态有效，且图结构能证明是共同剧情。
- `Allowed`：当前和直接下一句都能证明是共同剧情，既有导航也允许这一连接。
- `Next`：只有允许点击时返回直接下一句。
- `Code`、`Reason`：机器可判别的原因及用户提示。

共同线最后一句可以满足 `CurrentIsCommon=true`，同时由于下一步是分支、段落边界或结束而满足 `Allowed=false`。这样可以听完末句，再提醒暂停。它不会为了到达选择界面多点击一次，也不会选择分支。

判断不会只看空 `PathId`。分支入口、显式段落清单及从选项入口到出口之前的连接范围均属于分支；共同线须来自小节入口的直接链，或所有选项均有核实证据并实际连接到共同汇合点后的链。归档旧图不参与当前路线判定，无法确认的路线拒绝自动点击。

纯逻辑回归覆盖 schema 1／2／3 的可用共同线、完整分支禁止、手动确认汇合后的共同线、空 PathId 误标、嵌套分支、循环、返回、缺口、选择、条件矛盾、跨节、单句核对、原声、暂停，以及评估无副作用。

自然播放完成、屏幕仍处于游戏、识别结果对应本句、单次点击、等待游戏下一句、超时与旧事件丢弃，需由安卓会话和设备回归另行证明。本门控不会记忆“自动模式正在开启”，分支结束后必须手动重新开启由会话状态机负责。
