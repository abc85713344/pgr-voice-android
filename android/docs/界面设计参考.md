# 剧情档案界面 · 第二版

方向由用户选定：更像战双游戏内界面，使用场景封面、情报面板和明显的信息层次。

这些材料用于设计参考，没有将第三方界面截图或代码放入应用。浏览器插件连接当时不可用；公开页面内容、搜索参考图及已有游戏截图分别查阅，不声称安装运行过参考应用。

## 实际调整

章节页采用场景封面、醒目的章节编号和紧凑档案列表；当前台词放在下方独立面板。主要操作用实心红色，次要操作使用中性背景，减少重复红框。五页导航与悬浮控制使用同一组原生线条图标，并保留中文标签。台词列表把角色名和对白分开显示，完整状态可点按查看。没有用装饰进度条或波形冒充播放状态。

封面是本次原创生成的科幻场景，不是官方章节插画。应用只缓存一张缩小解码的静态封面，不播放背景视频或持续装饰动画。
