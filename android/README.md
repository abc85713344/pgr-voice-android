## 构建

工具实际安装在 `<AndroidEnv>`，通过英文目录连接 `<AndroidRoot>` 运行，以避开模拟器原生程序的中文路径问题。不会修改原 Windows SDK。

运行 `build-android.ps1 -Configuration Debug -Runtime android-x64` 构建模拟器包；真机运行 `build-android.ps1 -Configuration Release -Runtime android-arm64`。只支持 64 位 Android 10（API 29）及以上。API 36 编译，.NET 10、JDK 21。

执行 `sign-release.ps1 -InputApk <Release APK>` 生成可覆盖更新的签名包。首次建立独立发布密钥，之后重复使用同一密钥。`<AndroidEnv>\signing` 包含私钥和密码，应另行备份并保留；不要把这个目录放进公开发布包或源码仓库。

当前不裁剪构建显式设置 `AndroidEnableMarshalMethods=false`，使用运行时 JNI 注册。曾出现 Release 静态 marshal 表只有类型激活入口、遗漏 Activity 回调的启动错误；修改此配置后先按同一 Configuration/Runtime 执行 `dotnet clean` 再构建，以清除旧 Java 产物。静态 APK、签名和 Debug 回归通过仍不足以确认发布可用，必须安装最终签名 Release 验证冷启动及播放器实际操作。

## 使用顺序

1. 在章节页通过系统文件选择器导入一章 ZIP。ZIP 内可以保留原发布包的多层目录，但必须只有一个 `pack.json`，音频路径相对于该清单，支持 schema 1/2/3。
2. 打开章节，选择游戏中的小节和台词，确认后播放。恢复进度不会自动发声。
3. 开启悬浮控制并允许显示在其他应用上层。悬浮面板提供前后句、重播、暂停、分支、原声与 OCR 定位；可手动切换模式并确认位置。
4. 需要 OCR 时授予系统屏幕捕获权限。选择游戏应用或整个屏幕；设置字幕区域时先切回游戏，再框选角色名和完整对白。
5. 自动播放需要先核对当前位置并设置下一句点击区域；配音自然结束后，沿已核实路线推进。启用默认分支开关时，软件直接按所选默认路线配音，玩家自行点击游戏同一项；其他不确定、跳句和未核实内容仍需手动确认。
6. 游戏原声模式会冻结位置并停止外部配音；选择续接台词后恢复。连续两句文字相同时请使用手动“下一句”，避免把背景动画当成换句而重复播音。

锁屏、系统收回捕获或画面尺寸改变时，自动跟随暂停。手动功能仍可用。字幕区域按物理显示标识、物理像素尺寸与横竖方向分别保存，不依赖捕获画面的比例；只保存相对坐标，不保存截图。回到原屏幕可恢复区域，但仍需重新确认当前位置；旧版按比例保存的区域首次使用新版时需要重新框选。

## 音频与 OCR

“同时播放”优先保留游戏声音，不主动申请自动音频焦点；“配音优先”请求短暂降低其他应用音量。不同手机和游戏可能采取不同做法，须真机验证。两种策略都不更改游戏内音量。

安装包随附 PP-OCRv5 mobile ONNX 检测、识别模型，字典从模型元数据加载。测试版同时提供随包中文 ML Kit 对照引擎，同一时刻只加载一个引擎。无需账号、云 OCR 或 root；普通播放、OCR 定位和自动跟随不依赖无障碍服务。可选的“共同线自动播放”需要用户自行在系统设置中授权无障碍服务，才能在配音自然结束后点击指定的游戏下一句区域；未授权时仍可使用普通模式。

日常定位按需使用 OCR，不恢复旧版全程文字跟随。0.3.30按用户明确要求直接选择默认配音路线，不运行分支等待OCR。停止、切出游戏或改变位置会使旧请求失效；设置不会按温度自动调整。

## 配置及验收

骁龙 888 + 8 GB 是最低优化目标；8 Gen 2 / 8 Gen 3 + 12 GB 是推荐目标。目标不等于实测最低配置。X Fold5 和骁龙 888 的游戏同开、声音、发热及 30 分钟持续测试必须独立记录，模拟器不能代替。

回归基线及当前结果位于 `../reports/`。发布包必须附实际测试范围、SHA-256 和第三方组件说明。Debug 诊断入口仅在调试构建中启用，正式构建不会导出该入口。

## 源码边界

- `core/`：复用剧情规则、ZIP 原子导入、自动跟随安全决策。
- `AppSession.cs`：主线程串行调度，章节/模式/捕获变化使旧结果失效。
- `MainActivity.cs`、`Ui/`：五个原生页面、触屏操作和字幕框选。
- `Platform/`：MediaProjection 前台服务、悬浮控制和 Media3 音频。
- `Ocr/`：本地检测、裁切、识别与 ML Kit 对照。

原软件和章节音频不会被此工程覆盖；用户导入的数据保存在 Android 应用私有目录，卸载应用会删除这些数据，需先导出要保留的存档。
